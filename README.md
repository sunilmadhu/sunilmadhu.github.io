# sunilmadhu.me

Personal site of Sunil Madhu: founder of Socure, Instnt and Asyml8.

A single static page (`index.html`) with three.js, GSAP and Lenis loaded from CDNs. Media lives in `media/`.
Hosted on GitHub Pages at https://sunilmadhu.me.

To change the music, set `MUSIC.playlist` in `index.html` to a YouTube Music playlist link.
